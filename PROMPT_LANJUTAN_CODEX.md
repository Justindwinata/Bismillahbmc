## URUTAN IMPLEMENTASI — LAKUKAN SEKARANG, BUKAN HANYA TULIS RENCANA

### R0 — Audit source aktual, preservasi dan reproduksi tes (wajib sebelum coding baru)
- Inventaris semua file sumber yang sudah dibuat Codex, dependency/lockfile, migration, tests, evidence. Pastikan branch/commit dan catat uncommitted work. Validasi sumber aktual dan apa yang kosong. Review transitive minimatch override dan supply-chain/lifecycle policy. Periksa secret leakage di Git history dan output artefak tanpa membuka/mencetak secrets.
- Jalankan kembali `pnpm install --frozen-lockfile`, `pnpm check`, PostgreSQL integration menggunakan DB disposable, read-only smoke dan audit dependensi bila lingkungan mendukung. Jika perlu gunakan PostgreSQL native yang tersedia; Docker daemon sebelumnya unavailable, jangan mengklaim Compose PASS. Simpan full stdout/stderr dengan unique filename, timestamp, SHA256, perintah, exit code; redaksi secrets.
- Periksa M0/M1 acceptance, lakukan patch terhadap bug nyata, jangan ulang scaffold. Buat checkpoint Git. Laporan: `CODE_REVIEW_R0.md`, `EVIDENCE_MANIFEST.json`, `IMPLEMENTATION_STATUS.md` diperbarui, commit SHA dan isu prioritas.

### R1 — Prioritas produk tertinggi: real-time OBSERVE web vertical slice (implementasikan setelah R0)
- Buat `apps/web` Next.js App Router dan integrasi backend Fastify existing, PostgreSQL, API untuk candidate/pair/provider/chain status serta **SSE autentikasi** berbasis monotonically increasing persisted event cursor, reconnect + backfill + stale/error state. Jangan taruh service bearer token internal di browser bundle.
- Buat homepage terminal UI mengikuti `docs/07`: charcoal + subtle magenta, Overview, agent pipeline, live token feed, provider status, market network indicator, disconnected/stale, audit event drilldown, STOP status, wallet NOT_CONNECTED, equity UNKNOWN. **Jangan fabrikasi trade atau saldo.**
- Host browser di `localhost:3000` dengan API worker terpisah; worker tetap melanjutkan observasi saat tab/browser ditutup. Tes API/SSE integration, reconnect/out-of-order/429, sesi browser, Playwright screenshot/trace 1440×900 dan 390×844. Hasil R1 minimal: halaman **benar-benar dapat dibuka** dengan feed live read-only dari backend dan bukti screenshot.

### R2 — Intelligent market & on-chain wallet observation
- Enrich candidate dengan market pair/pool, liquidity, volume, token mint canonicalization; sumber waktu/slot/finality dan freshness; cache + quota; ukuran data provider tidak disamakan dengan finality.
- Implementasikan WS subscription/filtered address atau sumber indexer yang layak, reconnect/backfill/reorg-safe dedupe, watchlist public wallet, parse native/SPL swaps dengan evaluasi token account owner, threshold latency dan observed signal provenance. Buat `Copy Feed` yang mengusulkan mirror entry, **bukan menyalin trade otomatis saat OBSERVE**.
- Hitung dan tampilkan event age/ingest lag P50/P95 terukur; jangan menjanjikan latency rendah tanpa bukti/biaya RPC. Test malformed records, 429/503, events late/duplicate, stale data, source disagreement, browser reconnect.

### R3 — Eleven executable bot roles + genuine event deliberation + paper/shadow ledgers
- Bangun `DESK`, `SCOUT`, `FILTER`, `RUG CHECK`, `ANALYST`, `SNIPER/STRATEGY`, `SIZER`, `GUARD`, `EXECUTOR (simulated only)`, `LOGGER`, `EQUITY` menjadi modul/workers nyata sesuai `docs/03`, bukan sekadar daftar nama. Setiap tahap menyimpan `agent_event` typed, source/correlation IDs, proposal/dissent, reason codes, status, version, policy hash, latency dan output decision `BUY/SELL/SKIP` dengan alasan.
- Hard veto Guard/Security tetap deterministik. Kelola position entry/exit (termasuk slippage, unfillable quote dan illiquid token) di PAPER dan SHADOW yang terpisah dari data LIVE. Persiapkan accounting: lot, realized/unrealized P&L, fee, rent, reserve, deposits/withdrawals as capital flows not profit. Buat replay yang deterministik, concurrent budget reservations, no double buy, policy versioning.
- UI per-agent menunjukkan status dan trace nyata. Jika LLM disabled, label `RULE_ENGINE`/`DETERMINISTIC`, jangan membuat percakapan fiktif. Tambahkan opsi read-only LLM analyst hanya setelah kontrak API/cost cap jelas dan tidak memblokir deliverable inti.

### R4 — Full usable dashboard, Phantom, owner authentication and controls
- Selesaikan layar: Overview, Discover/Scanner, Smart Wallets, Copy Feed, Agents, Positions, Trades, Wallets, Risk, Audit/Logs, Settings, Beginner Setup. Semua berbasis API/database nyata; data unknown tidak berubah menjadi nol palsu.
- Implementasi login owner dan signing nonce via Phantom (challenge domain/expiry/one-time nonce/replay prevention), session HttpOnly/SameSite, CSRF, rate limits, RBAC, CSP, secure logout; wallet main read-only untuk balances dan manual deposit/withdraw guidance. Jangan mengimpor recovery phrase ke web/backend. Trading wallet terpisah belum auto-aktif.
- Implementasikan emergency STOP idempotent + durable HALTED, audit, policy caps UI dengan backend authorization. STOP menghentikan entry baru, **bukan jaminan membatalkan transaksi yang sudah broadcast**.
- Browser Playwright e2e, mobile, keyboard, security failure, disconnected, stale, fee-unavailable, open positions, paper audit, STOP. Review tampilan terhadap referensi visual.

### R5 — Execution implementation securely DISABLED (no real money)
- Integrasikan Jupiter `GET /swap/v2/order` dan `POST /execute` sesuai dokumentasi terkini; mode default hanya quote/unsigned flow. Buat allowlisted transaction/message/instruction verifier (fee payer, signer set, expected mints/amount limits, token extensions, ALTs, programs, rent, priority/network/platform fees, owner mandate). Provider order bukan trust anchor.
- Isolasi signer test-only di process terpisah; DB serialized reservations, unique intent lifecycle, chain receipt finality, post-trade balance reconciliation, `UNCERTAIN` quarantine, idempotency across crash/restart, no blind resubmission. Audit sign/send/confirm/failed and ledger reconciliation.
- Lakukan malicious transaction fixtures, bad ALT, wrong mint, source stale, concurrent budget attempts, signing denial, RPC timeout after broadcast, crash/restart, durable HALT, backup/restore drills. Full mainnet live mode remains disabled.

### R6 — Qualification, security, always-on ops (non-financial)
- Prepare local container/service supervisor and optional VPS deployment design with TLS, private networking, encrypted secrets/backup, restore verification, alerts, service health, provider failover, audit evidence and incident runbooks. No production deployment without approval/host credentials.
- Jalankan shadow/paper evidence berkelanjutan dan observation/soak sesuai resmi `G2/G3`, termasuk 7-day observation target dan 24-hour shadow actual duration bila masih disyaratkan; jangan mengubah durasi menjadi dummy PASS atau melaporkan menunggu sebagai selesai. Tes chaos, replay dan security review. **Self-review oleh agen yang sama tidak boleh disebut independent security audit.**

### R7 — Future owner-gated live verification, not authorized by this prompt
- Siapkan checklist dan secure setup untuk wallet trading modal kecil, private signer, network fees, caps, funding/recovery and explicit mode reauthentication.
- **STOP sebelum MICRO_LIVE.** Minta otorisasi terpisah setelah G0–G3 terpenuhi. Pengguna harus menyetujui wallet tertentu, cap, periode, dan risiko. Hanya dengan persetujuan baru boleh melakukan BUY/SELL mainnet nominal kecil dan membuktikan signatures/finality/deltas/accounting. **CAPPED_AUTO memerlukan persetujuan terpisah setelah micro-live PASS.** Tidak ada penarikan dana otomatis.
